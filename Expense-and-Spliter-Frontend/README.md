# Expense Tracker & Splitter Frontend (Vite + React)

This project has been upgraded to [Vite](https://vitejs.dev/) with React.

## Available Scripts

In the project directory, you can run:

### `npm run dev` (or `npm start`)

Runs the app in development mode with lightning-fast HMR.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### `npm run build`

Builds the app for production to the `dist` folder.\
It bundles React in production mode and optimizes the build for maximum performance.

### `npm run preview`

Locally previews the production build.
